Where Versus's Swap sits and how it looks. Each mock's Swap works (the fighters change sides). Every concept keeps to one colour per side, with no split box. Hover the buttons too: A and D change on hover.

Change buttons' icon:

Change uses ⇄ today, the same arrows as a swap, so a Swap button beside it reads as the same action twice. ▾ says what Change does (it opens the fighter list) and leaves the arrows to Swap. The mocks start with ▾.
